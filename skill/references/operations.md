# 维护与排障

已有安装先检查进程、状态、配置并备份；不要把全新初始化脚本指向旧部署。手动迁移兼容文件也要匹配版本指纹。运行中配置优先用本机 API，禁止打印完整模型配置。

| 现象 | 检查与修复 |
| --- | --- |
| connected但群不回复 | 看隔离微信是否停在扫码/手机确认页；确认小号在群，核对账号与群双白名单。 |
| 某群完全漏收 | 微信消息可能在 `message_1.db` 等分片。兼容版发现所有数字消息库，各库用自己的发送者映射；刷新同时检查WAL/SHM。 |
| 登录大号导致身份漂移 | 目录联接固定小号 `wechat_files_root`，不要把另一个号最新登录标记当机器人身份。 |
| 收到消息但没生成回复 | 检查模型认证、实际Planner/Replyer结果和余额；401不是扫码问题。 |
| 必须@ | 自然参与默认 `talk_value=1.0`；普通消息应进入Planner，仍允许模型选择安静。 |
| 很慢 | 分解接收、模型和微信投递耗时；关闭合并等待/模拟打字，正文合为一条，Flash关闭推理；工具和发图仍耗时，不能承诺秒回。 |
| UIA窗口失败 | 线程先进入隔离桌面再初始化COM；面板窗口检查成对初始化/释放。 |
| 图片成巨量文本 | 固定适配器把base64放媒体字段，段data交宿主识图，不能把base64塞上下文。 |
| 表情库为空/选不准 | 检查VLM/emoji模型和起始导入；只导入少量授权表情，勿扫其他聊天缓存。 |
| GIF静止 | 需多帧原文件投递；图片剪贴板会压成单帧。适配器保留贴纸标记。 |
| 表情无法解码 | 源码 `tools/ffmpeg/` 需完整官方EXE/DLL；普通照片图片密钥与数据库口令不同。 |
| 情话模式错乱 | 只认真实@目标和完整命令，持久化当前状态优先于旧聊天指令。 |
| 主动话题不来 | 普通接话与主动任务独立；查开关、时间、10分钟冷场、额度及真实session_id；从聊天流注册表解析，不自造hash。 |

只重载发生变化的层：模型/插件配置可热更新，桥接源码变更才重启自己的桥接；核PID命令行和目录，保留微信/MaiBot。被自动审批拦截后不绕过。不要结束无关Python、关闭其他微信、删除微信数据、卸载驱动或覆盖虚拟环境。配置备份只保存在运行目录。
