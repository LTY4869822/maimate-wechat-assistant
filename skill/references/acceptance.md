# 验收

安装完成不等于群聊完成，逐层保留证据和未完成项。

1. `manage.py verify`：固定包版本、兼容文件、回环地址、令牌一致，其他群/私聊拦截；不打印密钥。
2. `verify --live`：两服务及两个插件加载、所选账号、入站和OneBot；同时查看隔离微信实际聊天主界面。只读检查不发消息。
3. 模型：MaiBot模型测试接口实测认证/工具/视觉；搜索另看实际调用，不以保存成功代替可用。
4. 群聊：另一账号 @机器人「你好」，核实收信、生成、投递和手机文本；再普通消息验证自然参与。
5. 功能：问实际人数；动态GIF在手机确认会动；当天新闻实际搜索附来源；@开/关高情商模式。主动话题仅用户要求启用后验证。

只向用户选择的群发送已授权测试；发送超时先核已有发信证据，不自动重发。

无语音兼容基线曾通过Flandora767、适配器118、群工具46项测试，并在一台Windows+微信4.1.15.56完成真实群回复、人数、联网、主动话题、情话和动态GIF验收。新机器需重新扫码与群收发；测试数不是兼容所有版本的保证。
