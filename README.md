# 麦伴 MaiMate

让自己的微信群多一位自然接话的聊天伙伴。麦伴是围绕 [MaiBot](https://github.com/Mai-with-u/MaiBot) 和 [Flandora](https://github.com/OMSociety/Flandora) 整理的 Windows 部署工具与通用 Agent Skill，提供固定版本的离线安装包。

> **项目状态：** v1.2.0。首次安装及实际群聊需要使用者自行填写模型密钥、扫码登录并选择群聊。请让群成员知晓机器人身份。

## 能力

- 普通群消息自然接话，支持被 @ 时优先回应；可选低频主动开话题。
- 使用 DeepSeek 接口联网检索新闻并附来源；可查询当前群人数。
- 发送多帧动态 GIF；支持在群里 @ 小号开启或关闭高情商土味情话模式。
- 限定账号和目标群，其他群聊与私聊默认拦截。支持保留已有设置、失败后续跑。
- 提供 WorkBuddy、豆包工作及其他本机 Agent 可读取的通用 Skill 入口。

## 下载与安装

在 [Releases](../../releases) 下载完整离线包，完整解压后双击 `自动配置群聊助手.cmd`。该包包含 Python、固定依赖、源码归档及资源，安装时不需要访问 GitHub 或 PyPI。

1. 准备 Windows 10 22H2 / Windows 11 x64、约 6 GB 空间、兼容的官方电脑版微信、已在目标群的小号和自己的 DeepSeek API Key。
2. 安装后，在本机窗口填写密钥并阅读使用条款；在 Flandora 向导中扫码并手机确认。
3. 选择目标群。用另一个微信账号发消息，核对实际收发、群人数、搜索和手机上的 GIF 动画。
4. 需要启用主动话题时在选择窗口中开启；在群里 @ 小号并发送「启动高情商模式」或「关闭高情商模式」。

完整离线包内含同版本小型 Skill ZIP。若使用 Agent，先在技能管理界面导入它，再在 **Windows 本机任务**中要求 Agent 使用本地离线包配置群聊助手。当前 WorkBuddy 已验证技能包可被读取；豆包客户端导入及端到端流程尚未实测，具体取决于客户端的本机文件和命令执行权限。

## 运行边界

离线是指**安装过程**无需下载。微信收发、模型推理与新闻搜索仍需要网络。电脑关机、休眠、断网或微信退出后，机器人会停止；项目不包含腾讯微信客户端或任何账号。微信版本更新可能影响桥接；当前验证组合是 MaiBot 1.3.16、Flandora 1.0.0、Windows 微信 4.1.15.56。项目不承诺秒回、全天候在线或兼容所有客户端版本。

该方案使用个人微信桌面自动化及第三方桥接，不属于腾讯官方提供的微信机器人接口；使用者需要自行了解平台规则与账号风险。密钥只在本人机器填写，不放到聊天或仓库中。

## 代码结构

```text
skill/SKILL.md                   Agent 技能入口
skill/scripts/                   离线安装及配置脚本
skill/references/                部署、平台兼容与验收说明
skill/assets/compat/             针对固定版本的兼容修改
skill/assets/wechat-group-tools/ 群功能插件、表情与风格素材
THIRD-PARTY.md                   第三方许可与源码来源
```

完整源码归档、运行时、依赖及第三方许可在离线发行包中。源码仓库与离线包分开发布，因为完整包约 870 MiB；不要仅下载源码 ZIP 就以为已包含全部离线依赖。

## 验证与问题反馈

离线包在隔离目录完成安装与重复安装，新增群工具及安装器相关测试 90 项通过；桥接和适配器沿用原版通过的测试基线。各项测试不等同于在每台电脑上完成微信扫码、实际收发及每个 Agent 客户端验证。

反馈问题时请提供操作系统、微信版本、故障步骤及脱敏错误信息；不要提交 API Key、微信登录数据、聊天记录、令牌或完整运行日志。
